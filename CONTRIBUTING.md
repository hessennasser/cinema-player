# Contributing

Thanks for helping improve Cinema Player.

1. Fork the repository and create a focused branch.
2. Run `swift test` before opening a pull request.
3. Keep new user-facing strings clear and accessible.
4. Preserve the local-first promise: no tracking, uploads, or network dependency without explicit discussion.
5. Include screenshots for visual changes and explain manual playback testing where relevant.

For local development:

```sh
swift run CinemaPlayer
```

For an app bundle:

```sh
zsh Scripts/build-app.sh
```
